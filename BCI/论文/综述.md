# 一、Brain-Computer Interfaces for Communication and Control   


EEG 研究主要围绕两种基本范式展开：

1. 诱发电位（Evoked Potentials）
  - **定义**：由特定事件引起的**短暂波形**对**持续脑电活动的瞬时扰动**
    - 与刺激事件具有相位锁定（phase-locked）特定，即每次刺激都会在相同时间出现相似的脑电响应
  - **分析方法**：通常采用时域平均（time-domain averaging）的方法进行分析
    - 通过对大量相同事件对应的脑电信号进行平均，以提高信噪比并提取稳定的神经响应
2. 振荡特征（Oscillatory Features）
  - 也可能由特定事件诱发，但通常不具有相位锁定特性
  - **分析方法**：更常采用频谱分析（spectral analysis）方法研究

&nbsp;

&nbsp;

两种范式对应两大典型BCI

1. **诱发电位类 BCI（Evoked Potential-based BCI）**
  - P300 BCI
  - SSVEP（稳态视觉诱发电位）
  - VEP（视觉诱发电位）
  - 特点：**准确率高、训练时间短**。
2. **脑电振荡类 BCI（Oscillation-based BCI）**
  - 运动想象（Motor Imagery, MI）
  - μ 波（8–13 Hz）
  - β 波（13–30 Hz）
  - 特点：**无需外部刺激，更符合自然交互，但训练难度较高**。
